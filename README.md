# Groundtruth

Groundtruth is a WebMCP-native OpenTelemetry observability platform for humans and their own agents. It ingests metrics, logs, and traces, then exposes the same live investigation, visualization, and incident context through both the interface and typed site tools. Groundtruth reads and displays; fixes remain the job of the user's agent and existing infrastructure access.

The project is being built in the open for the WebMCP Challenge. The first release will include a self-serve hosted experience, a fully open source self-hosted stack, and instrumented example infrastructure.
